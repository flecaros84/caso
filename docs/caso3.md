# Caso 3: Asistente Inteligente para Evaluación de Candidatos en Selección de Personal 

Una empresa de tecnología quiere agilizar y estandarizar el proceso de preselección de candidatos. Dispone de currículos, evaluaciones previas, feedback de entrevistas y puede acceder a fuentes externas como perfiles de LinkedIn y GitHub. Busca desarrollar un agente que cruce información, priorice candidatos y explique los motivos de la priorización, resguardando criterios éticos y de diversidad.

Requisitos clave:

● Detección de variables y criterios relevantes para preselección.

● Prompts claros para extracción y justificación de puntajes/prioridades.

● Pipeline RAG que integre datos internos y externos.

● Arquitectura que garantice trazabilidad y auditoría ética.
